- Changed a dream experiment arm's `finalPolicyId` (and the CLI's `final policy ... changes N` line) to report the last deployed policy, the one that grew the arm's last tree, so it can no longer contradict the round table; the post-hoc `selectBestPolicy` winner on the arm's own pool is now the separate `selectedPolicyId` (`selected policy` in the CLI). A `result.json` without `selectedPolicyId` predates the split and its `finalPolicyId` is the selected policy.
- Added `scoring` (`deterministic` or `timing`) to the experiment result and the CLI header, and qualified the "round 1 is identical across arms" claim in `help dream` and the python-speedup result note: it holds by construction for deterministically scored tasks, while a wall-clock-scored task's round-1 scores differ within timing noise.
- Fixed `help dream` to list `--beta1`/`--beta2` in its usage and Options; the usage string is now the one `dream` itself prints on a usage error, and its `--task` list follows the task registry.
