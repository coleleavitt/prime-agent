- Added the Engineer Trajectory Index (ETI): a derived, off-turn-path diff over the sealed learning-index days that buckets them into observed ISO-week windows and labels each failure fingerprint NEW, DROPPED (internalized), or PERSISTS (stable-gap), with a new-minus-retired rate. Every claim carries a non-empty confound flag (task-mix always, plus tool-surface / measurement-instrument across a corpus boundary or a data gap), no label is emitted below a minimum observed-window count, and security/credential-class fingerprints are exempt from DROPPED suppression. `prime-agent learning trajectory` seals and prints the table (or `--json`); `--include-backfill` folds in the offline cross-tool backfill days (confound-flagged, CLI table only, never persisted or prompted). The store is one global gitignored file under `~/.prime/agent/learning/trajectory.json` (mode 0600, temp+fsync+rename under a lock, validate-on-read), and `PRIME_AGENT_TRAJECTORY_INDEX=0` disables it.
- Added the `trajectory-backfill` skill: an offline, read-only Python generator that reconstructs LearningDay-shaped day files from the prime, Claude Code, and opencode session corpora for `learning trajectory --include-backfill`. It calls no provider, touches no network, never opens auth files, and emits only structural error-class tokens.
