- Added Workspace Recall: when a top-level session's agent run ends it writes a per-repo mark of HEAD, the index, dirty-path digests and the names of skip-worktree paths missing on disk (never file content, `digestAlgorithm: "sha256-128"`) to `<agentDir>/recall/<basename>.<sha256(repoRoot)[:16]>.json`, and the first `ipython` result of a top-level session in a repo with a mark gets a `<workspace_recall>` block of at most 2 KB naming changed paths, counting unchanged ones and listing what could not be verified.
- Added build claims to Workspace Recall: a `bash()` build or test command (`tsc`, `tsgo`, `biome check`, `cargo test`, `npm test`, `pytest`, `go test`, `make` and similar) that exits 0 in an ipython cell while the workspace digest holds still is kept, up to 8 per repo, and shown CURRENT only while the workspace still matches, including which skip-worktree paths a sparse checkout left off disk, otherwise EXPIRED with a reason.
- Added `PRIME_AGENT_WORKSPACE_RECALL` (`0`, `off`, `false` or `no` disables Workspace Recall); RLM child sessions never write a mark or receive a block.
- Added a 1 s deadline to each Workspace Recall step on the tool path; a missed deadline skips that process's tool-path recall for the repo for 60 s, and a git timeout skips the repo for 10 minutes in every process sharing the agent dir.
- Added `recall.mark`, `recall.witness` and `recall.digest` spans.
- Added `bashCommands` to `ipython` tool result details: the secret-redacted text and exit code of each `bash()` command that finished while the cell ran, sent on the kernel's `done` frame and absent from older runtimes.
