- Added `prime-agent dream experiment` (alias `compare`) and the in-session `dream.experiment(...)` skill call / `/dream experiment` command, which run the Dream-RSI loop against the paper's Recursive Fixed Exploration control: every arm from the same initial policy, seed, clock and per-round budget, the `fixed` arm never dreaming, so round 1 is identical across arms by construction, with one tree store per arm under `experiments/<id>/<arm>` and a versioned `result.json` (`prime-agent.dream.experiment/1`) carrying per-round records and the headline multipliers (calls to the control's final best, best at equal budget), which are null rather than clamped when undefined.
- Added `fixedPolicy` and `initialPolicy` options and per-round `rounds` records (probes, per-role handler calls, tokens, the dreaming step or null) to both loop drivers, `runDreamLoop` and `runDreamLoopWithAgent`, with `dream.fixed_policy` on `dream.run` and `dream.redeploy`.
- Added the semantic-guidance ablation arms `dream-guided` / `fixed-guided` on the LLM-proposer path: a `dream.llm_guidance` child call per iteration digests the frozen pool's recorded artifacts and scores into directional insights prefixed to the proposer prompt, falling back to empty guidance on failure; iteration 0's prompt is unchanged.
- Added `DreamRunService.startExperiment` and the `dream.experiment` host request, sharing the single run slot, cancel relay and `dream_run_update` stream with `dream.run`; `DreamRunStatus` gains optional scalar `kind`, `experimentId`, `arm`, `armIndex`, `armCount`, `round`, `rounds`, `cumulativeProbes` and `resultPath` fields, a backward-compatible additive change with no protocol bump. Guided arms require the LLM proposer and are rejected before any call; the standalone CLI runs local arms only at zero tokens.
- Wired the `python-speedup` task's public contract (`PYTHON_SPEEDUP_PROMPT_CONTEXT`) into the in-session LLM proposer prompt; it was previously never passed.
- Added `evals/dream/plot_experiment.py`, which turns one or more experiment result files into the paper's evidence figures (round-best vs round, cumulative best vs cumulative discovery calls with the control's target and equal-budget lines, attempts per round with policy changes marked, and the headline card) plus a self-contained HTML report whose captions come from the result metadata, with `--check` for a stdlib-only table view and an interpreter fallback when the system python lacks matplotlib.
