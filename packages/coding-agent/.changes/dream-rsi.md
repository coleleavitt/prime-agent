- Added `prime-agent dream`, a Dream-RSI (Zheng et al., 2026) loop that grows a discovery tree over a local scored task, freezes each tree into a zero-cost replay simulator, and improves a typed, serializable exploration policy by local search over its parameters; the default `loop` on circle-packing runs the whole rollout/replay/dream/redeploy cycle at zero model tokens and no network.
- Added the `dream` subcommands `rollout`, `replay`, `improve`, `loop`, `status`, and `show` (with aliases `propose`, `simulate`, `inspect`), all pure argv-in/exit-code-out with output through an injected io, deterministic under an injected seed and clock.
- Added a soundness gate: an exploration policy is data, never code — parsed through a schema that rejects unknown keys, out-of-range numbers, and unknown named rules — and the `--llm-proposer`/`--llm-dreamer` flags are rejected by the standalone CLI because they require an in-session agent handler, so the CLI never spends a token or opens a socket.
