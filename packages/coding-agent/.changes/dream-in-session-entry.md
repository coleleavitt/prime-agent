- Added in-session Dream-RSI entry points alongside the standalone `prime-agent dream` CLI: a bundled `dream` kernel skill (`await dream.run(task=...)`, `dream.status()`, `dream.cancel()`), a `/dream` session slash command, and a live `dream_run_update` progress event so a run's phase, best node score, and final policy score are visible in the Agents View.
- Added `DreamRunService`, a background wrapper around the async Dream-RSI driver that owns one run per session, relays a cancel, and pushes a scalar `DreamRunStatus` snapshot at each phase boundary; it opens no span of its own because `runDreamLoopWithAgent` already mints the detached-root `dream.run` span that carries the launching turn's `trigger.trace_id`.
- Kept the default token-free: with `llm_proposer`/`llm_dreamer` unset the run uses the local zero-token proposer and dreamer and never calls the model, and a dreamed policy stays data parsed by the strict policy parser, never executed. The in-session surfaces are available only in a depth-0 session with self-improvement allowed, matching `/refine` and `/ravo`.
