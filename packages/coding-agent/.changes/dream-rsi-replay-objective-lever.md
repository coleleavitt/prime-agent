- Changed the Dream-RSI replay objective: the parallelism bonus (which cancelled the probe cost exactly whenever a replay used all k1 rounds, so "the same best for fewer probes" never won) is replaced by an anytime term, a charged cost that counts out-of-support cells, and an uncapped rounds-saved bonus (`beta1` 0.05, `beta2` 0.10, `beta3` 0.25); replay now uses the same improvement epsilon as online rollouts.
- Added per-candidate dreaming verdicts (winner, tie, worse, quality-rejected, unmeasurable, identical, duplicate), a deterministic lever scan per dreaming step, a `dreams/<run>.jsonl` log beside every dream store, `dream.candidate` spans, and exact probe curves (`probesToRoundBest`, `improvements`) on every round record.
- Added optional pool priming (`primingPolicies`, the fixed `PRIMING_DIVERSE` set) and a clock-free `runLabel` for dream loops so experiment arms no longer share a run id; the local mutator no longer proposes changes to fields replay cannot measure (`branchWidth`, `refineDepth`, `recoveryPolicy`).
