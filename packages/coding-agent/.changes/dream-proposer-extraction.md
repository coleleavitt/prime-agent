- Fixed the Dream-RSI LLM proposer silently replacing most child candidates with local mutations: a child's JSON object is now extracted from around code fences and prose (`extractJsonValue`, opt-in for dream children; RAVO's strict parsing is unchanged), so an answer wrapped in an explanation is accepted, and an accepted candidate enters the tree as `origin: "llm"` while a fallback is `origin: "local"`.
- Changed the proposer prompt into an explicit contract: the task context names the exact size (`taskPromptContext(task, resolveTaskN(spec))`, so autocorrelation says "exactly 64 weights", not "n"), carries a parseable shape example, forbids prose, fences and thinking out loud, and ends on the JSON-only instruction; the policy dreamer prompt ends on its JSON-array-only instruction too.
- Added rejection provenance for every refused child result: the reason (`parse`, `shape`, `invalid-candidate`, `error`, `length`, `aborted`, `turn-limit`, `budget`), child status, tokens and a 240-character output excerpt go on the `dream.llm_propose` span (`dream.llm_reject_reason`, `dream.llm_status`, `dream.llm_output_tokens`, `dream.llm_attempts`, `dream.llm_reject_excerpt`, `dream.origin`) and into a per-run JSONL log at `<dreamDir>/rejections/<runKey>.jsonl`; per-round records and experiment rows now carry the proposer tally (`llmProposals`, `llmAccepted`, `llmRejected` by reason, `localFallbacks`) and `agentGeneratedCalls`.
- Changed the proposer retry rule: a result cut at the child's output cap (`stop_reason: length`) is classified `length` and is not retried, so a runaway child is never paid for twice.
