- Added a RAVO referee: when a refinement that creates or updates a Python skill claims to fix a recurring failure, the verified replay cases that probe what the skill imports are re-executed in a subprocess, and the claim is rejected when the failure still happens or a case cannot run.
- Added the `not_applicable` referee verdict for a claim no replay can speak to (a memory or prompt fix, a skill that imports something else, or a failure with no derivable probe); such a claim stands on its provisional observation window instead.
- Changed a claim on a failure whose applicable replay cases never reproduced it (`no_evidence`) to fail closed instead of passing on the claim alone.
- Changed replay cases to cover only a missing module and a missing distribution (`PackageNotFoundError`), derived only from the kernel's own traceback for an ipython cell that raised; a stored case of any other kind, including a `from X import n` name probe, is dropped from the failure ledger when it is next loaded or written and is never run, listed, made a referee opponent or counted as evidence.
- Changed failure records to keep up to 8 distinct replay cases in `replayCases`, only missing-module and missing-distribution probes, reading a legacy single `replayCase` on load.
- Changed replay self-checks to run off the turn path in a `ravo.replay_verify` span, one batch at a time, merging verified cases into the ledger at the next flush; only a verified case is listed as `replay=verified`.
- Changed replay runs to use isolated mode in a fresh temporary directory with only PATH, HOME, LANG (on Windows also SYSTEMROOT, WINDIR, USERPROFILE, TEMP, TMP, COMSPEC and PATHEXT) and explicit PYTHONPATH roots, to refuse private module paths and modules that act on import, to kill the interpreter's process group on timeout, abort, host exit, SIGINT, SIGTERM, SIGHUP or SIGQUIT, and to record each live group in the orphan process journal so supervisor recovery reaps it after a worker is killed outright.
- Changed the skill dry-run screen to import skills in the same environment referee adjudication uses (PATH, HOME, LANG, and a PYTHONPATH of the explicit roots, the toolforge package roots and the host's PYTHONPATH entries) instead of the full process environment, and in a fresh temporary working directory like the referee's, so its `cwd` option only resolves relative roots.
- Changed the RAVO deep gate to honour the judge's own pass/fail/abstain verdict instead of always passing it.
