- Added `refinement.committed`, `refinement.applied_unmeasured` and `refinement.rejected` log records for every proposal a `ravo.run` or `/ravo` evaluates, with reason `ravo_run` and, on a rejection, its `cause`, so `prime-agent learning` counts RAVO run commits; a commit is logged as addressing a failure only when the judge also named it (as `<fp>` or `failure:<fp>`) and the gate did not charge it.
- Added the `ravo_run` reason to the refinement events a RAVO run records in harness state.
- Fixed `ravo.run(global_=True)` and `/ravo --global` reading, gating against and committing into the session's harness store while stamping the edits global; a global run now uses the global harness store and its failure ledger, and commits under the harness state lock, waiting for it without blocking the session, so a failure record another session flushes meanwhile is kept.
- Fixed a RAVO run commit overwriting RAVO state written while the run was going: a regression recorded on the lineage meanwhile is kept, and a champion or evaluation another refinement saved stops the run with `stale_cas` instead of being replaced.
- Changed the local-scope guidance a RAVO run gives its children to record a transient condition only together with how to re-check it, and to update or delete it once it changes.
