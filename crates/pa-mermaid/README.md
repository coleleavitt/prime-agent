# pa-mermaid

The fork's Mermaid diagrams (fork feature crate, `docs/fork-feature-crates.md`): a Rust port of lovely-mermaid
0.3.3 — the renderer the fork's TS product moved to from grok-mermaid 0.2.3 — and the fork's diagram policy: a
flowchart too wide for the terminal is redrawn on the other axis (TD↔LR), a diagram that still does not fit keeps its
source with a note giving the columns it needs, and art whose source had unreadable statements is drawn with the
first warning listed under it.

Behavioural spec: `packages/coding-agent/src/modes/interactive/components/mermaid.ts` (`rotateFlowchart`,
`layoutMermaid`) and `test/mermaid.test.ts` on `perf/session-catalog-resume` (commit `a358fd19e`), and the
lovely-mermaid 0.3.3 package itself (npm tarball, integrity `sha512-EMLJS934…H5A==`, the lockfile's).

## Scope

- **Renderer** (`render`, `render_cached`, `diagram_kind`): every diagram type lovely-mermaid 0.3.3 draws — flowchart
  (subgraphs, kebab-case ids, `id@{shape: …}` nodes, double-bordered diamonds, quote-aware `|labels|`, inline labels
  with `=`/`.`/`-`, parallel labels joined `one / two`, adjacent back edges returning locally, straight skips, packed
  labelled lanes), state (composites as titled frames, `--` regions, scoped `[*]`, accumulating descriptions), class
  (`class A["Label"]`, cardinalities at their own ends), ER (quoted names, per-end cardinalities), sequence
  (activations as double lifelines, a note left of the first participant), pie, mindmap, timeline, gitGraph, a
  frontmatter `title:`, lenient parsing everywhere, size caps that truncate with a warning. Rows are runs of one
  `Role`; widths are display columns of an installable grapheme measure (`set_width_measure`; the package's own
  `unicode-width` rule by default).
- **Policy** (`layout`, `rotate_flowchart`): `Layout::Art { art, notices, rotated }` (`rotated`: the axis a too-wide flowchart was redrawn on) or `Layout::Source { notices }` for one
  fence at the available width, notices omitted while streaming: `Mermaid diagram drawn left to right|top to bottom
  to fit <w> columns` (info), `Mermaid diagram incomplete: <first warning>[ (+n more)]`, `Mermaid diagram not drawn:
  needs <n> columns, <w> available` (the narrower of the two axes), `… no statement could be parsed`, `… <header> is
  not supported in the terminal` (info).

## Non-goals

- The package's `sourceBox`, `toAnsi`, and class-style helpers, which the TS product never called; author classes
  (`:::name`, `class A,B name`, `cssClass`), link targets (`click`/`link`), and `classDef`s are parsed but not
  carried: they only split the package's runs and drive its own ANSI styling, while the product styles by role.
- Where diagrams are drawn and how they are painted: that is the TUI's (`pa_tui::diagram`, `markdown::mermaid_blocks`,
  the agent-message body); this crate answers layouts only.
- Telemetry: drawing is a paint-path reaction of an existing surface with no user action to count, the TS commit
  emits nothing, and the TUI has no telemetry seam.

## Public API

`render(src) -> Option<Art>`, `render_cached(src) -> Arc<Option<Art>>`, `diagram_kind(src) -> Option<DiagramKind>`,
`Art { rows: Vec<Vec<ArtSpan>>, width, warnings }`, `ArtSpan { text, role }`, `Role`, `DiagramKind`;
`layout(src, width, streaming) -> Layout`, `rotate_flowchart(src) -> Option<Rotated>`, `Layout`, `Notice`,
`NoticeLevel`, `Rotated`, `Axis`; `set_width_measure(fn(&str) -> usize) -> bool`.

## Seams

- `pa_tui::diagram::DiagramRenderer`, installed once by `pa-cli` behind `feature = "mermaid"`
  (`crates/pa-cli/src/mermaid_diagrams.rs`, from `features::install_tui_features`): `layout` maps this crate's
  `Layout` onto the TUI's `DiagramLayout`; `draws_on` opts into agent messages (received and sent from ipython cells),
  custom messages, and `/btw` answers. The measure installed is `pa_tui::width::str_width`, the one the transcript
  wraps and pads with. This crate depends on no workspace crate.

## Files owned

None on disk. In the tree: `src/render/goldens.json` (renderer parity corpus, 78 cases) and `src/policy_goldens.json`
(policy corpus), generated by `scripts/lovely-mermaid-goldens.mjs` from lovely-mermaid 0.3.3 and marked 18.0.7 under
node, which also writes the TUI seam's goldens (`crates/pa-tui/src/markdown/diagram_transform_goldens.json`,
`crates/pa-tui/src/custom_message/diagram_text_goldens.json`). `LICENSE-lovely-mermaid` (Apache-2.0) ships beside the
port.

## Telemetry

None (see Non-goals).
