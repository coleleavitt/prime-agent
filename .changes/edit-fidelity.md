- The `edit` skill keeps a file's line endings, byte-order mark and encoding (it rewrote CRLF files as LF), takes `replace_all=True`, creates a file from an empty `old_str`, matches straight quotes against curly ones, and refuses an edit to a file that changed on disk since the model read it (`kernel.editReadCheck`: `stale` by default, `read` for Claude Code's read-before-edit rule, `off`). New: `edit.write` (whole-file writes through permissions, /rewind and the diff display), `edit.notebook_read` / `edit.notebook_edit` (Claude Code's NotebookEdit), PDF pages in `attach_image(..., pages="1-5")` and `attach_image.pdf_text`, and `bash(command, timeout=seconds)`.
