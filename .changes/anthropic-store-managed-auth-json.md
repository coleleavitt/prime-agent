- Anthropic (shared account store): an `auth.json` Anthropic login that the pi or opencode plugin already moved into `~/.anthropic-accounts` (refresh token `managed-by-anthropic-accounts`) is no longer reported as malformed on every start; it is treated as the store's, so its stale access token is not served and the placeholder is never sent as a refresh token. A genuinely malformed login is reported once per process.
